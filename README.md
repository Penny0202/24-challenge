24 Challenge｜24 點數字挑戰

一款以數學運算為核心的互動式網頁遊戲。玩家需要運用四個隨機產生的數字，透過加、減、乘、除及括號進行計算，讓最終結果等於 24。

遊戲規則
- 每回合隨機產生四個 1～13 的數字。
- 四個數字都必須使用，且每個數字只能使用一次。
- 可以自由使用加、減、乘、除及括號。
- 計算結果等於 24 即挑戰成功。

主要功能
隨機出題：自動產生具有解答的題目。
難度選擇：提供簡單、普通、困難三種難度。
遊戲模式：支援自由練習與限時挑戰。
答案驗證：自動檢查算式及計算結果。
提示功能：提供解題提示與參考答案。
成績紀錄：記錄得分、連勝次數及最高分。

 使用技術
- HTML5
- CSS3
- JavaScript
- LocalStorage
- GitHub Pages

如何遊玩
1. 開啟遊戲網頁，選擇模式與難度。
2. 點擊數字及運算符號組合算式。
3. 提交答案，確認計算結果是否為 24。
4. 挑戰更多題目，累積分數並刷新最高紀錄。
